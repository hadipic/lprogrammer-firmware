## 🔌 ۱. اتصال به دستگاه

### مرحله ۱: تنظیم آدرس ESP32
- آدرس IP را در فیلد `🌐 آدرس ESP32` وارد کنید
- یا روی دکمه `🔄 تشخیص خودکار` کلیک کنید

### مرحله ۲: انتخاب پروتکل
- از منوی `📡 پروتکل` پروتکل مورد نظر را انتخاب کنید:
  - **UART** - ارتباط سریال (TTL/RS232)
  - **SPI** - حافظه‌ها و سنسورها
  - **I2C** - سنسورها و EEPROM
  - **CAN** - خودرو و صنعتی
  - **OBD-II** - عیب‌یابی خودرو
  - **KNX** - اتوماسیون ساختمان
  - **DALI** - کنترل نور
  - **Modbus** - صنعتی
  - **و ۴۰+ پروتکل دیگر**

### مرحله ۳: اتصال
- روی دکمه `🔌 Connect` کلیک کنید
- وضعیت اتصال را در بالا سمت راست ببینید

## 📝 ۲. کار با ترمینال

### ارسال داده

| روش | توضیح | مثال |
|-----|-------|------|
| **Text** | متن ساده | `Hello` |
| **HEX** | داده هگزادسیمال | `9F` یا `FF 01 02` |
| **JSON** | دستورات پیشرفته | `{"tx":"9F","rx_len":3}` |

### دکمه‌های ارسال

| دکمه | کاربرد |
|------|--------|
| `📤 Send` | ارسال متن/JSON |
| `HEX Send` | ارسال به صورت HEX |
| `⏎ NL` | ارسال Newline (`\r\n`) |

### کاراکترهای خاص

| دکمه | معادل |
|------|-------|
| `CR` | `\r` (Carriage Return) |
| `LF` | `\n` (Line Feed) |
| `CRLF` | `\r\n` |
| `TAB` | `\t` |
| `ESC` | `\x1b` |
| `NUL` | `\x00` |

## 📜 ۳. اسکریپت‌ها

### ساختار اسکریپت

```javascript
// کامنت (اجرا نمیشه)
echo پیام نمایشی
speed 300          // سرعت اجرا (میلی‌ثانیه)
delay 1000         // تاخیر
wait 2000          // منتظر دریافت داده
loop 5             // حلقه ۵ بار
    {"tx":"9F","rx_len":3}
    delay 100
end
```

### دستورات اسکریپت

| دستور | توضیح | مثال |
|-------|-------|------|
| `//` | کامنت | `// این خط اجرا نمیشه` |
| `echo` | نمایش پیام | `echo سلام` |
| `speed` | سرعت اجرا | `speed 300` |
| `delay` | تاخیر به میلی‌ثانیه | `delay 1000` |
| `wait` | منتظر دریافت داده | `wait 2000` |
| `loop` | حلقه تکرار | `loop 5 ... end` |
| `pause` | مکث | `pause` |

### دکمه‌های اسکریپت

| دکمه | کاربرد |
|------|--------|
| `📥 Example` | انتخاب اسکریپت آماده |
| `📂 Load` | بارگذاری از فایل (`.lps`) |
| `💾 Save` | ذخیره اسکریپت |
| `🗑️ Clear` | پاک کردن |
| `▶ Run` | اجرا |
| `⏹ Stop` | توقف |

## ⚡ ۴. ماکروها (Quick Commands)

ماکروها دکمه‌های سریعی هستند که بر اساس پروتکل انتخاب شده تغییر می‌کنند.

### ماکروهای SPI

| دکمه | دستور JSON |
|------|-----------|
| `📟 JEDEC ID` | `{"tx":"9F","rx_len":3}` |
| `📊 Status 1` | `{"tx":"05","rx_len":1}` |
| `✏️ Write Enable` | `{"tx":"06","rx_len":0}` |
| `🗑️ Chip Erase` | `{"tx":"C7","rx_len":0,"delay_ms":3000}` |
| `📖 Read 16B @ 0` | `{"tx":"0300000010","rx_len":16}` |

### ماکروهای UART

| دکمه | دستور |
|------|-------|
| `AT` | `AT` |
| `AT+GMR` | `AT+GMR` (نسخه) |
| `AT+CWMODE=1` | `AT+CWMODE=1` (Station) |
| `AT+CWLAP` | `AT+CWLAP` (اسکن WiFi) |

### ماکروهای OBD-II

| دکمه | دستور |
|------|-------|
| `01 00` | `0100` (PIDs) |
| `01 0C` | `010C` (RPM) |
| `01 0D` | `010D` (Speed) |
| `03` | `03` (Read DTCs) |
| `04` | `04` (Clear DTCs) |

## 🔍 ۶. عیب‌یابی

### اتصال قطع می‌شود

| علت | راه حل |
|-----|--------|
| آدرس IP اشتباه | از دکمه `🔄 تشخیص خودکار` استفاده کنید |
| ESP32 خاموش | دستگاه را روشن کنید |
| WiFi قطع | اتصال WiFi را بررسی کنید |

### پیام "Not connected"

| راه حل |
|--------|
| روی `🔌 Connect` کلیک کنید |
| آدرس IP را بررسی کنید |
| پروتکل صحیح را انتخاب کنید |

### اسکریپت اجرا نمی‌شود

| راه حل |
|--------|
| `//` را از ابتدای خطوط بردارید |
| از دستورات صحیح استفاده کنید |
| روی `▶ Run` کلیک کنید |

## 📋 ۷. مثال‌های کاربردی

### مثال ۱: خواندن JEDEC ID از SPI Flash

**اسکریپت:**
```javascript
{"tx":"9F","rx_len":3}
delay 100
echo ✅ JEDEC ID received
```

### مثال ۲: راه‌اندازی ILI9341 LCD

**اسکریپت:**
```javascript
{"rst_pulse":10}
delay 120
{"tx":"11","rx_len":0}
delay 120
{"tx":"29","rx_len":0}
delay 100
echo ✅ ILI9341 initialized
```

### مثال ۳: تست OBD-II

**اسکریپت:**
```javascript
ATZ
delay 1000
0100
delay 500
010C
delay 500
echo ✅ OBD-II test complete
```

### مثال ۴: اسکن I2C

**اسکریپت:**
```javascript
{"cmd":"scan"}
delay 500
echo ✅ I2C scan complete
```

## 🎯 ۸. نکات مهم

1. **پروتکل را قبل از اتصال انتخاب کنید**
2. **برای SPI حتماً `rx_len` را مشخص کنید** (مگر اینکه `rx_len=0` باشد)
3. **اسکریپت‌ها به صورت خودکار در مرورگر ذخیره می‌شوند**
4. **ماکروها با تغییر پروتکل تغییر می‌کنند**
5. **از تب Hex برای مشاهده داده‌های باینری استفاده کنید**
6. **برای ذخیره لاگ از دکمه `💾 Save Log` استفاده کنید**
