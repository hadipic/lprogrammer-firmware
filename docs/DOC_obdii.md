## J1850 VPW (کد AVR) vs K-Line ISO 9141 (کد PIC)

| ویژگی | **J1850 VPW** (کد AVR) | **K-Line ISO 9141** (کد PIC) |
|--------|------------------------|------------------------------|
| **پروتکل** | J1850 VPW | ISO 9141-2 (K-Line) |
| **خودروها** | **آمریکایی** (GM, Chrysler, Ford قدیمی) | **اروپایی و آسیایی** (BMW, Benz, Toyota قدیمی) |
| **سرعت** | 10.4 kbps | 10.4 kbps |
| **سطح ولتاژ** | ۰-۷ ولت (VPW) | ۰-۱۲ ولت (K-Line) |
| **مدولاسیون** | **Variable Pulse Width** | **UART استاندارد** |
| **بیت ۱** | ۱۲۸ میکروثانیه HIGH | UART bit 1 |
| **بیت ۰** | ۶۴ میکروثانیه HIGH | UART bit 0 |
| **پین‌ها** | **۱ پین** (Half-Duplex روی یه سیم) | **۱ پین** (Half-Duplex - K-Line) |
| **سخت‌افزار** | اپ‌امپ + مقایسه‌گر | تراشه L9637D یا اپ‌امپ |
| **CRC** | CRC8 مخصوص J1850 | Checksum ساده (جمع بایت‌ها) |
| **فرمت پیام** | 3-byte Header + Data + CRC | 3-byte Header + Data + Checksum |

---

## تفاوت اصلی: نحوه رمزگذاری بیت‌ها

### J1850 VPW:
```
بیت ۱: +------+      (128us HIGH, 64us LOW)
         |      |
         +------+
         
بیت ۰: +--+          (64us HIGH, 64us LOW)
         |  |
         +--+
```
**Variable Pulse Width** - هر بیت یه پالس با عرض متفاوت

### K-Line ISO 9141:
```
بیت ۱: +----------+  (UART - سطح HIGH)
         |          |
         +----------+
         
بیت ۰: +----------+  (UART - سطح LOW)
         |          |
         +----------+
```
**UART استاندارد** - مثل سریال معمولی

## چرا این مهمه؟

| VPW (AVR) | K-Line (PIC) |
|-----------|--------------|
| **نیاز به bit-bang دقیق** | **UART سخت‌افزاری** |
| تایمر + GPIO + وقفه | فقط UART |
| کد پیچیده (CRC, Pulse Width) | کد ساده |
| **نمیشه با UART ESP32 فرستاد** | **میشه با UART ESP32 فرستاد!** |

**ولی J1850 VPW نیاز به bit-bang داره** - همون کدی که برات نوشتم.

## ۱. بیدار کردن ECU (Wake-up Sequence)

### روش K-Line (ISO 9141-2) - استاندارد:

```
مرحله ۱: K-Line رو ۲۵ms به GND بکش (Wake-up Pulse)
         K-Line: ‾‾‾‾‾‾\_________/‾‾‾‾‾‾
                        ↑ 25ms ↑

مرحله ۲: ۱۰۰ms صبر کن (ECU بیدار بشه)

مرحله ۳: ECU شروع به ارسال 0x55 (01010101) با baud rate خودش میکنه
         ECU: 0x55 0x55 0x55 0x55...

مرحله ۴: دیاگ baud rate رو تشخیص میده (sync)

مرحله ۵: دیاگ جواب میده با 0x33 (یا آدرس ECU)

مرحله ۶: ECU با 0x55 جواب میده → ارتباط برقرار شد!
```

---

### کد بیدار کردن:

```c
// ============================================================
//  K-Line Wake-up Sequence (ISO 9141-2)
// ============================================================
#include "protocol.h"
#include "driver/gpio.h"
#include "driver/uart.h"
#include "esp_log.h"

static void kline_wake_up(int uart_num, int tx_pin) {
    // ۱. K-Line رو ۲۵ms به GND بکش
    gpio_set_level(tx_pin, 0);  // LOW
    esp_rom_delay_us(25000);    // 25ms
    
    // ۲. K-Line رو آزاد کن (HIGH)
    gpio_set_level(tx_pin, 1);  // HIGH
    
    // ۳. ۱۰۰ms صبر کن
    vTaskDelay(pdMS_TO_TICKS(100));
    
    // ۴. منتظر 0x55 از ECU باش
    uint8_t sync_byte;
    int timeout = 0;
    while (timeout < 200) {  // 2 ثانیه تایم‌اوت
        int len = uart_read_bytes(uart_num, &sync_byte, 1, pdMS_TO_TICKS(10));
        if (len > 0 && sync_byte == 0x55) {
            ESP_LOGI(TAG, "✅ ECU Wake-up: 0x55 received");
            break;
        }
        timeout++;
    }
    
    if (timeout >= 200) {
        ESP_LOGE(TAG, "❌ ECU Wake-up failed!");
    }
}
```
